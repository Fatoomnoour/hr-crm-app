# نظام إدارة الموارد البشرية (HR CRM)

تطبيق ويب بسيط لإدارة بيانات الموظفين باستخدام Python و Flask.

## 🌟 المميزات
- ➕ إضافة موظفين
- 👀 عرض الموظفين
- ✏️ تعديل البيانات
- 🗑️ حذف السجلات
- 🔍 تصفية حسب القسم
- 📱 تصميم متجاوب
- 🌐 دعم عربي كامل

## 🛠️ التقنيات
- Python 3.8+
- Flask
- SQLAlchemy
- SQLite
- HTML/CSS
